# Разработка AI-агента для трейдинга с LLM-интерпретацией»

---

### **Описание проекта**

Проект посвящен разработке автономного AI-агента для работы на финансовых (в т. ч. криптовалютных) рынках, соединяющего классические алгоритмы машинного обучения, статистический риск-менеджмент и языковые модели (LLM). В условиях высокого уровня шума и нестационарности финансовых временных рядов ключевой целью системы является не точное прогнозирование цены, а корректное определение вероятности движения актива для принятия прибыльных и рисково-оптимизированных торговых решений.

---

### **Архитектура системы**

Архитектура проекта состоит из трех основных уровней:

1. **Слой обработки и подготовки данных (Data Pre-processing Layer):**
Загрузка, очистка, Feature Engineering и разделение временных рядов без утечек данных с помощью метода `TimeSeriesSplit`.
2. **Предиктивное ядро (ML Core) и Ансамблирование:**
Комбинация разнородных ML-моделей для поиска скрытых рыночных паттернов:
* **XGBoost Classifier:** Консервативный классификатор («Снайпер») с высокой точностью (*Precision* = 0.60) и минимальным количеством ложных срабатываний.
* **LSTM (Recurrent Neural Network):** Нейросеть с качественной калибровкой вероятностей (*Log Loss* = 0.6315) и 100%-й точностью при высоком пороге уверенности (>0.886).
* **HMM (Hidden Markov Model):** Модель скрытых марковских цепей для идентификации текущего рыночного режима (3 скрытых состояния).
* **Meta-Learner Ensemble:** Мета-модель на базе логистической регрессии, объединяющая сигналы базовых моделей для итогового предсказания.


3. **Слой управления рисками и агента (Orchestration & Agent Layer):**
* **Критерий Келли (Kelly Criterion):** Расчет оптимального размера позиции для максимизации долгосрочного капитала и защиты от банкротства.
* **LLM & LangChain/LangGraph:** Оркестрация на базе языковой модели `Llama-3.1-8b` (через Groq API / Ollama), интерпретирующая математические выходы предиктивного ядра и предоставляющая пользователю четкие аналитические рекомендации через ReAct-агента без «галлюцинаций».



---

### **Основные результаты и выводы**

* Проведена валидация предиктивных моделей на хронологических данных с применением метрик *Precision, Recall, F1-Score, Log Loss* и *Calibration Curve*.
* Выявлена высокая избирательность **XGBoost** и качественная вероятностная оценка **LSTM** в зонах высокой уверенности.
* На основе анализа работы **Meta-Ensemble** сделан важный практический вывод: мета-обучение на базе стандартной логистической регрессии в условиях сильного шума может снижать точность (деградация *Precision* до 0.214). В результате обоснована необходимость перехода к алгоритмам с жесткими фильтрующими правилами (*Hard Logic*).
* Успешно реализован и протестирован интерактивный агент-интерпретатор, строго соблюдающий правила принятия решений (SELL/WAIT/BUY) на основе данных предиктивного ядра.

### **Ключевые технологии и инструменты**

* **Languages & Libraries:** Python, PyTorch (LSTM), XGBoost, HMMlearn, Scikit-learn, Pandas, NumPy.
* **Agent Infrastructure:** LangChain, LangGraph, Groq API (Llama-3.1-8b), Ollama.
* **Cross-Validation:** `TimeSeriesSplit`.
